Comprendre les accès, la confidentialité et les limites
Deux boîtes distinctes : « Mail iCloud » ouvre directement iCloud Mail. Les boutons « Lire dans Gmail » ouvrent le courriel précis à son emplacement d’origine dans Gmail ; ils ne peuvent pas ouvrir ce même identifiant dans iCloud. Aucun transfert de messages entre comptes n’est effectué.
Confidentialité : ce site GitHub est public. Aucun courriel, identifiant ou contenu personnel n'est publié dans son code. La base de suivi est privée dans Supabase après connexion ; les données éventuellement importées localement restent non chiffrées dans ce navigateur jusqu'à leur transfert. N'y conserve pas de secrets.
