Connexion et assistant ELOAH

Le mode Recherche active le Web ; les autres modes sont conversationnels. Les questions et jusqu’aux quatre derniers échanges sélectionnés sont transmis au fournisseur IA. Des frais API peuvent s’appliquer. Aucun document privé n’est lu automatiquement.

La recherche mémorielle exclut le coffre, les dossiers personnels sensibles, les mails et les comptes clients. Les passages retenus sont transmis au moteur IA sélectionné.
