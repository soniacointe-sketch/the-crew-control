10/ CONSTRUIS UN SYSTÈME DE DESIGN VISUEL COMPLET

Agis comme un directeur de marque senior et directeur créatif. Construis un système de design visuel cohérent pour [MARQUE / PROJET]. Définis la direction créative, la palette de couleurs, le système typographique, les règles d'espacement, le style des icônes, la direction de l'imagerie, les éléments graphiques, les principes de mise en page et le langage visuel pour les réseaux sociaux. Assure-toi que chaque élément fonctionne avec les autres pour former une identité reconnaissable sur [PLATEFORMES]. Style : [STYLE]. Le système doit être moderne, évolutif, cohérent et facile à appliquer par une équipe de design professionnelle sur les contenus futurs.

# 10/ CONSTRUIS UN SYSTÈME DE DESIGN VISUEL COMPLET

Agis comme un **Senior Brand Director, Creative Director et Design Systems Lead**. Construis un système d’identité visuelle complet, distinctif et immédiatement reconnaissable pour **[MARQUE / PROJET]**, destiné à **[PUBLIC CIBLE]** et déployé sur **[SITE WEB / INSTAGRAM / FACEBOOK / LINKEDIN / PRINT / APP / PACKAGING / AUTRES]**.

L’objectif n’est pas simplement de proposer de beaux éléments graphiques, mais de créer un **véritable langage visuel cohérent, reproductible et évolutif**, capable de guider toute une équipe de designers, créateurs de contenu et développeurs.

### 1. DIRECTION CRÉATIVE

Définis clairement :

- le concept créatif central ;
- la personnalité visuelle de la marque ;
- l’émotion dominante à transmettre ;
- 3 à 5 mots-clés de direction artistique ;
- ce qui doit rendre cette identité immédiatement reconnaissable ;
- ce que la marque doit absolument éviter visuellement.

Style recherché : **[LUXE / ÉDITORIAL / CINÉMATIQUE / MINIMALISTE / FUTURISTE / BRUTALISTE / ORGANIQUE / PREMIUM / AUTRE]**.

### 2. PALETTE DE COULEURS

Construis une palette complète comprenant :

- couleur primaire ;
- couleurs secondaires ;
- couleur d’accent ;
- couleurs neutres ;
- couleurs de fond ;
- couleurs fonctionnelles si nécessaire.

Pour chaque couleur, indique :

- nom ;
- HEX ;
- usage recommandé ;
- associations autorisées ;
- niveau de contraste.

Prévois également les règles pour fonds clairs, fonds sombres et contenus numériques.

### 3. SYSTÈME TYPOGRAPHIQUE

Définis :

- typographie principale ;
- typographie secondaire ;
- éventuelle typographie d’accent ;
- hiérarchie H1 / H2 / H3 / corps / légendes / CTA ;
- graisses ;
- tailles relatives ;
- interlignage ;
- espacement des lettres ;
- usage des majuscules ;
- règles desktop/mobile.

La typographie doit créer une identité forte, pas seulement être lisible.

### 4. GRILLE ET ESPACEMENT

Crée un système cohérent pour :

- marges ;
- paddings ;
- espacements verticaux ;
- espacements entre blocs ;
- largeur maximale des contenus ;
- grille desktop ;
- grille tablette ;
- grille mobile ;
- rayons de bordures ;
- proportions des composants.

Utilise un système facilement reproductible par une équipe professionnelle.

### 5. STYLE DES ICÔNES

Définis :

- trait ou plein ;
- épaisseur ;
- niveau de détail ;
- géométrie ;
- angles ou courbes ;
- style des pictogrammes ;
- tailles recommandées ;
- règles d’utilisation.

Les icônes doivent appartenir au même univers visuel que le reste de la marque.

### 6. DIRECTION PHOTO & IMAGE

Définis précisément :

- sujets ;
- cadrages ;
- profondeur ;
- lumière ;
- contraste ;
- grain ;
- colorimétrie ;
- textures ;
- environnement ;
- traitement des portraits ;
- placement des produits ou objets ;
- niveau de réalisme.

Précise également ce qu’une image conforme à la marque doit transmettre émotionnellement.

Évite tout rendu générique, artificiel ou reconnaissable comme du contenu IA standard.

### 7. ÉLÉMENTS GRAPHIQUES SIGNATURE

Crée plusieurs éléments identitaires propriétaires :

- formes ;
- motifs ;
- lignes ;
- cadres ;
- textures ;
- symboles ;
- overlays ;
- découpes ;
- effets photographiques ;
- traitements typographiques ;
- éléments de mouvement.

Ils doivent permettre de reconnaître la marque même lorsque le logo n’est pas visible.

### 8. PRINCIPES DE MISE EN PAGE

Définis les règles de composition :

- hiérarchie ;
- point focal ;
- alignements ;
- rythme ;
- asymétrie ou symétrie ;
- espace négatif ;
- densité visuelle ;
- rapport texte/image ;
- composition éditoriale ;
- logique des CTA.

Prévois plusieurs familles de compositions afin d’éviter que tous les contenus paraissent identiques.

### 9. SYSTÈME POUR LES RÉSEAUX SOCIAUX

Développe un langage cohérent pour :

- posts 1:1 ;
- posts 4:5 ;
- stories 9:16 ;
- reels ;
- carrousels ;
- couvertures ;
- annonces ;
- citations ;
- contenus éditoriaux ;
- lancements ;
- témoignages ;
- promotions.

Crée plusieurs templates visuels distincts mais immédiatement reconnaissables comme appartenant à la même marque.

### 10. SYSTÈME DIGITAL / WEB

Définis les règles pour :

- hero sections ;
- cartes ;
- boutons ;
- formulaires ;
- navigation ;
- titres ;
- images ;
- séparateurs ;
- blocs éditoriaux ;
- CTA ;
- footer ;
- responsive.

Le passage du desktop au mobile doit conserver exactement la personnalité de la marque.

### 11. MOTION DESIGN

Si pertinent, définis :

- vitesse des animations ;
- transitions ;
- apparition des textes ;
- mouvements d’images ;
- comportements au scroll ;
- micro-interactions ;
- animations de logo.

Le mouvement doit renforcer la personnalité de la marque et non devenir décoratif.

### 12. RÈGLES DE COHÉRENCE

Établis des règles très claires :

**TOUJOURS**
- ce qui doit rester constant ;
- les signatures visuelles obligatoires ;
- les combinaisons recommandées.

**JAMAIS**
- les couleurs interdites ;
- les typographies incompatibles ;
- les effets à éviter ;
- les clichés visuels ;
- les compositions qui affaiblissent l’identité.

### 13. EXEMPLES D’APPLICATION

Montre comment le système fonctionnerait sur au minimum :

- une page d’accueil ;
- un post Instagram ;
- une story ;
- un carrousel ;
- une affiche ;
- une publicité ;
- une couverture éditoriale ;
- un CTA commercial.

### 14. DESIGN TOKENS

Termine par une synthèse utilisable par une équipe de design ou de développement avec :

- couleurs ;
- typographies ;
- tailles ;
- espacements ;
- rayons ;
- bordures ;
- ombres ;
- ratios d’image ;
- règles responsive.

### EXIGENCE FINALE

Ne construis pas une simple planche d’inspiration.

Construis un **véritable système de design visuel de marque**, suffisamment précis pour qu’une équipe différente puisse créer des dizaines de contenus pendant plusieurs années tout en donnant l’impression qu’ils ont été dirigés par le même directeur artistique.

Le résultat doit être :

**distinctif · premium · cohérent · mémorable · modulaire · évolutif · reproductible · professionnel**

Chaque décision graphique doit avoir une fonction et contribuer à la reconnaissance immédiate de la marque.

Celui-ci peut devenir ton **prompt n°10 de référence** pour construire ensuite directement le Brand Book complet de **Power & Glam, The Crew ou n’importe quelle nouvelle marque**.

# POWER & GLAM  
## VISUAL DESIGN SYSTEM — V1.0

### 01 — POSITIONNEMENT VISUEL

**Power & Glam n’est pas une marque de développement personnel classique.**

C’est une maison éditoriale féminine contemporaine construite autour de cinq territoires :

**AMOUR · BEAUTÉ · ARGENT · VIE · DÉSIR**

Le langage visuel doit exprimer simultanément :

**puissance · sensualité · intelligence · profondeur · autonomie**

La marque ne doit jamais devenir :
girly, naïve, ésotérique caricaturale, cheap, influenceuse lifestyle générique ou « coach Instagram ».

### CONCEPT CENTRAL

**LA CIRCULATION DU VIVANT**

Chaque univers représente une forme de circulation :

- EAU — je ressens
- PEAU — j’habite
- TERRE — je possède
- VIE — je déploie
- FEU — je décide

Phrase manifeste :

**JE SUIS VIVANTE.**

**ÉDITORIAL**  
**CINÉMATIQUE**  
**ORGANIQUE**

## Ressenti recherché

Power & Glam doit donner l’impression d’être à mi-chemin entre :

un magazine haut de gamme,

# 05 — RÈGLE COULEUR

Une création appartient toujours à :

**1 univers dominant + palette institutionnelle.**

Exemple :

Crème  
Noir  
Émeraude

et éventuellement une micro-touche rouge P&G.

Jamais cinq couleurs d’univers simultanément sauf :

- carte des univers ;
- manifeste de marque ;
- navigation globale ;
- présentation institutionnelle.

# 11 — ANTI-AI-LOOK

Une image Power & Glam est rejetée lorsque :

- la peau semble artificielle ;
- les proportions corporelles sont étranges ;
- les arrière-plans semblent générés ;
- les détails sont impossibles ;
- l'éclairage n'a aucune logique ;
- la composition ressemble à une banque d'images IA ;
- le visage paraît trop parfait ;
- l'image semble générique.

Objectif :

**photographie éditoriale avant illustration IA.**

# 15 — LAYOUT SIGNATURE

Les compositions Power & Glam suivent généralement :

**IMAGE / VIDE / MOT**

IMAGE + TITRE + 12 INFORMATIONS + BOUTON + ICÔNES.

Chaque création doit avoir un point focal évident.
