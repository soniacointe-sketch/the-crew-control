Atelier documentaire

Stockage local uniquement. Les documents et fiches restent dans ce navigateur (sauf export volontaire). Aucun fichier n’est envoyé sur GitHub ou vers un serveur ELOAH. N’ajoute pas de données nominatives sur les mineurs, de santé ou autres informations confidentielles. Les PDF contenant du texte et les DOCX peuvent être lus localement dans le navigateur via des bibliothèques JavaScript externes. Les scans sans texte nécessitent un traitement OCR séparé. Aucun fichier n’est transmis par notre code à un serveur de traitement ; les bibliothèques doivent cependant être téléchargées depuis un CDN.
